# Portfolio — Akhmadou Bamba Diouf

Portfolio d'étudiant en M1 Cybersécurité (Efrei Paris) : expériences, projets (bastion Guacamole, SIEM Wazuh, IDS/SIEM, audit OWASP), certifications et veille cyber.

- `index.html` : version française · `en.html` : version anglaise
- `assets/` : style, scripts, photo
- `vercel.json` : en-têtes de sécurité HTTP (CSP, HSTS, X-Frame-Options…)

Site statique, sans dépendance ni étape de build. Aucun script ou style en ligne (CSP stricte).
Hébergé sur Vercel ; la section Veille est mise à jour chaque semaine.
